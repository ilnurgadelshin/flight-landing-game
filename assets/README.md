# Visual assets

`textures/countryside.jpg` is an AI-generated fictional aerial albedo texture, created with
the built-in image-generation tool and saved as a 1254 × 1254 JPEG (about 744 KB) for browser delivery. It is not geographic
imagery or navigation data. The original generated PNG is kept outside the project; the game
uses only the bundled JPEG. Three.js' RoundedBoxGeometry is vendored from the installed Three.js
package under its existing MIT license.

Generation prompt:

> Use case: photorealistic-natural. Asset type: seamless aerial ground albedo texture for a real-time flight simulator, square 2048 by 2048. Create a realistic orthographic satellite photograph looking exactly vertically down over 6 kilometers of temperate European agricultural countryside. Many organically subdivided fields of muted sage green, olive, wheat straw, brown tilled soil and dark green hedgerows, irregular believable parcel boundaries, visible fine plough lines, small woodland clusters, very sparse tiny farm roofs and narrow country lanes. Photographic fine detail at every scale, natural uneven crop growth, subdued earthy colors, no repeating grid. Perfectly flat diffuse overcast illumination with no directional cast shadows, no perspective, no horizon, no sky, no labels, no text, no airport or runway, no large water bodies, no bright artificial colors. Fill the entire square edge to edge. The edges should tile seamlessly with matching rural land cover. This is an albedo asset mapped onto actual 3D terrain, not a rendered screenshot or concept art.
